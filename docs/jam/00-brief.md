# GET THEE TO A NUNNERY — Jam Brief

Weekend game jam. Team of three: Designer, Coder, Director.

## Non-negotiables from the client

- Title: **Get thee to a Nunnery**
- A nun. A shotgun.
- HTML game, playable in a browser.
- Full gameplay loop (title → play → lose/win → score → replay) with an element of progression.
- MEGA FUN. Polished. Juicy.

## Constraints (Director's call)

- Single self-contained `index.html`: vanilla JS + Canvas 2D + Web Audio. No frameworks, no external assets, no network requests. All art is drawn procedurally on canvas (or encoded inline). All sound is synthesized with Web Audio.
- Desktop-first: keyboard + mouse. Touch is a nice-to-have, not required.
- Must hold 60fps on an ordinary laptop.
- A run lasts 3–8 minutes. The "one more go" factor is everything.
- Jam scope: roughly a weekend of work. Cut ruthlessly. Ship a small thing that is great, not a big thing that is okay.

## Success criteria

1. Someone who has never seen it is playing within 5 seconds of the title screen.
2. Firing the shotgun feels AMAZING. This is the whole game.
3. There is a reason to keep playing: progression within a run, and a reason to come back (high score, unlocks).
4. No bugs that break a run.

## Process

1. Designer writes a pitch. Coder writes a tech memo. In parallel.
2. They swap, critique, and argue. Director breaks ties.
3. Director writes the agreed design doc.
4. Coder builds. Director playtests in a real browser. Designer reviews. Repeat until it is polished.
